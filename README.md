## Escenario Elegido
Escenario D – Estadísticas de Resultados Deportivos

## Descripción del Dataset
Este proyecto analiza estadísticas de equipos de fútbol utilizando Python y archivos CSV

Se trabajó con:
- cantidad de partidos ganados
- tabla de posiciones
- promedio de goles
- gráficos comparativos de rendimiento

## Instrucciones de Ejecución
1. Clonar el repositorio.
2. Ejecutar el script: `!python scripts/analisis_deportes.py`.
3. Los resultados se guardarán en la carpeta `/resultados` [4, 5]
4. Para ejecutar el archivo de python en visual studio code se necesita poner pip install pandas
